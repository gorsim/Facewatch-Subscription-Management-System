Quick start

  1. Login with your account. If it is the first time for the seeded admin, change the password when prompted.
  2. Upload the Delivered and Installed CSV files.
  3. Click Generate Stock List.

Working the list

  • Filter using search, Cam Type, and Location.
  • Check Show Missing Only to focus on items with missing counts.
  • Use the Physical checkbox, Notes field, and Location select per row.
  • Use Bulk actions: Tick All/Untick All (confirmation shown), or Tick/Untick by location.
  • Export: CSV for a data file, PDF for a printable checklist.
  • Click Save and Close to save progress for the selected date.

Mobile tips

  • Swipe horizontally to scroll the table, or switch to Cards view with larger touch targets.
  • Filters and bulk actions still apply to the card view.

Locations

  • Click Manage Locations to add, rename, or remove locations.

Users and passwords

  • Admins can manage users under Users.
  • Everyone can change their password under Account.
  • Password policy: minimum 12 chars, include upper, lower, digit, and special, must not contain your username, avoid common passwords.

Troubleshooting

  • If a button seems unresponsive, refresh the page (hard refresh) to reload scripts.
  • If CSV upload fails, check the file format/encoding; CSVs should have a Camera Code column.
